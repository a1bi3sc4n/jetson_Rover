Rover Explained:

- This project aims to acheive autonomous navigation of a rover using the machine learning capabilities
- That can be programmed onto a Jetson Board due to its 32 Tensor Cores, allowing for live object detection using CNNs
- Helping (through the use of a camera) identify a target object and follow it.
- I succesfully achieved this by:
  -Increasing power input on the motors
  -Reducing spin rate on the spot when the object isn't detected
  -Using a more opaque, distinct object opposed to a transparent glass as the target object.
